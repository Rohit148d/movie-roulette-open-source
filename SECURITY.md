# Security policy

Please do not open a public issue containing exploitable security details,
API secrets, account data, or signing material. Use GitHub's private
vulnerability reporting feature when available, or privately contact the
repository maintainer using the contact method listed on their GitHub profile.

## Supported versions

Security fixes target the most recent development branch and supported
release. Older Android APKs and deployed builds may need separate updates.

## Reporting guidelines

Include a description, steps to reproduce, affected version, expected/actual
behavior and impact. Remove secrets, user data, and any third-party credentials
from reproduction files. Please allow time for a coordinated fix.

No security audit is a guarantee that the software is vulnerability-free.
